# Reference

FPM 参考文献、综述和方法拓展目录。

## 当前主题

本目录主要保存与 FPM 复现实验相关的拓展资料：

- FPM 理论、发展和应用综述；
- 高通量快速 FPM 研究进展；
- sparse sampling FPM；
- subwavelength resolution Fourier ptychography；
- LED 阵列位置误差校正；
- adaptive system correction；
- noise-robust adaptive step-size；
- AI + optical imaging 相关启发。

`阅读论文.md` 可作为文献阅读索引和读后问题清单。

## 同步建议

公开 GitHub 仓库中建议优先保留：

- 自己整理的 `阅读论文.md`；
- DOI/链接索引；
- 关键公式和实验参数摘要；
- 与代码复现直接相关的注释。

PDF 原文是否提交需要单独确认版权和再分发权限。
