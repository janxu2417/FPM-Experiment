## 同步建议

报告目录采用“PDF 公开、docx 本地编辑”的策略。Word 源文件默认不进入公开主仓库，原因是：

- 二进制文件不利于 Git diff；
- 可能包含未整理的图片、批注或本地信息；
- 报告中的论文图、实验数据或样品信息可能需要单独确认授权。

公开版本建议使用 PDF 或 Markdown，并在报告中明确：

- 实验参数；
- 数据批次；
- 代码 commit；
- 重建 preset；
- 关键图像和评价指标；
- 尚未解决的问题。
