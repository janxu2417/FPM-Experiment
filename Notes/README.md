## 建议写法

新的 Markdown 笔记建议包含：

- 论文题目、作者、年份、DOI/链接；
- 核心问题和主要贡献；
- 成像模型、关键公式和变量单位；
- 实验参数；
- 与本项目复现实验的关系；
- 尚未解决的问题。

Word 源文件适合作为本地编辑稿；公开同步时优先导出或整理为 Markdown。
