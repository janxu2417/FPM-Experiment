# Differential Phase Contrast (DPC)

Differential Phase Contrast（DPC）相关资料目录。

## 与 FPM 的关系

DPC 和 FPM 都可以利用 LED 阵列进行角度编码照明。DPC 更强调通过不对称照明获得相位梯度并恢复定量相位；FPM 则通过多角度低分辨率图像在频域拼接高分辨率复振幅。

对本项目而言，DPC 资料主要用于理解：

- LED 阵列显微镜中的明场、暗场和相差成像；
- 定量相位梯度成像；
- 照明编码和相位传递函数；
- FPM 与 DPC 在相位恢复、照明 NA 和频域覆盖上的联系。
