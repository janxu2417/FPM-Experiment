# Original Paper

FPM 原始论文和核心论文资料目录。

## 说明

本目录用于本地保存论文 PDF，便于离线阅读和标注。由于论文 PDF 的再分发权限不一定明确，公开同步到 GitHub 时建议只提交本 README 和自己的阅读笔记，不直接提交 PDF 原文。

## 当前主题

当前资料主要覆盖：

- 2013 Nature Photonics 宽视场高分辨率 FPM；
- 高速 FPM；
- LED 阵列 multiplexed coded illumination；
- 2021 Nature Reviews Physics 综述；
- 空间带宽积；
- FPM 定量相干传递函数恢复；
- 基于凸优化的 FPM 研究。
